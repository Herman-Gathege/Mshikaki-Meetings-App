# Mshikaki

> "We came to the meeting to play. Somehow we left with assigned tasks."

Mshikaki is a lightweight, playful collaboration tool for team sessions: play an
icebreaker, capture ideas, record decisions, assign real work, and end up with an
automatic audit trail of everything that happened.

**Status: goal / discovery. No application code yet.**

This repository currently holds the MVP 1 concept, scope, domain model, risks and
plan. Read it in the order below before writing code.

## The one loop

```
PLAY -> CONNECT -> THINK -> DISCUSS -> DECIDE -> ASSIGN -> DO -> RECORD
```

Everything in MVP 1 exists to make that loop work inside a single meeting, and to
leave a trail behind it.
